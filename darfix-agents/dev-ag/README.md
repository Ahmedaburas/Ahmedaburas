# Dev.Ag — DARFIX developer agent

Explores UI/UX and frontend/backend quality, ranks user-impacting gaps, and reports remediations.

## Run

```bash
export DARFIX_ADMIN_EMAIL=…
export DARFIX_ADMIN_PASSWORD=…
cd ../darfix-agents
npx @grok/agent-sdk dev .
# http://127.0.0.1:3000/dev-ag
```

## Tools

- `darfix_health`
- `darfix_ux_audit`
- `darfix_dev_report_outline`
