# Ahmed-HSE App

HSE management platform for a steel fabrication yard, restored and linked to this GitHub repository:

**https://github.com/Ahmedaburas/Ahmedaburas**

The app lives in [`hse-platform/`](./hse-platform/). Open that folder for the yard register (incidents, observations, risk assessments, permits, inspections, actions, training, and heat stress).

## Run

```bash
cd hse-platform
npm start
```

Open http://127.0.0.1:4780

```bash
cd hse-platform
npm test
```

Requires Node.js 22.13+. The database is created locally at `hse-platform/data/hse.sqlite` (not committed).
